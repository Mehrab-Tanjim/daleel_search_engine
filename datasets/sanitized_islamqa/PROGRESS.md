# Review progress

The source contains 5,343 extracted Quran citation records. Three reviewers recorded 755 individual decisions in review_decisions_0.jsonl through review_decisions_2.jsonl. These are model-assisted relevance decisions, not an independently verified complete dataset. The remaining 4,588 citations have not been reviewed. Existing 53-pair sample has separate review as documented in ISLAMQA_REVIEW.md.

Each id has split, source row and extracted reference index. Decisions can include corrected verse references. Original train and benchmark data must stay separate. Complete per-pair review, citation validation, independent sampling, and source permission checks remain before production or evaluation use.
